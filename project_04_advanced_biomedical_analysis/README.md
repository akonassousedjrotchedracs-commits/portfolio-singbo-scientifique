# Projet 04 — Analyse statistique biomédicale

## Objectif

Quantifier les proportions observées et leur incertitude dans un jeu de démonstration.

## Méthodes et méthodologie

Les données sont auditées, puis les proportions de résistance et les intervalles de Wilson à 95 % sont présentés par organisme et antibiotique.

## Résultats

- [Estimations et intervalles](results/amr_estimates_with_wilson_ci.csv)
- [Audit qualité](results/data_quality_audit.json)
- [Graphique des intervalles](results/amr_wilson_intervals.png)

## Interprétation et limites

Les intervalles sont larges avec de petits effectifs. Cette analyse ne remplace ni une étude clinique, ni un outil de prescription. Les données sont synthétiques.
