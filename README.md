# Portfolio scientifique — AKONASSOU SEDJRO TCHÉDRAC SINGBO

Portfolio public de projets en biotechnologie médicale, microbiologie, bioinformatique, SQL et analyse statistique biomédicale.

## Ce que présente ce dépôt

Chaque fiche expose l’objectif, les méthodes, la méthodologie, les résultats synthétiques, l’interprétation et les limites. Les tableaux et graphiques publiés sont issus de jeux de démonstration synthétiques.

5. [Mémoire de soutenance sur le diagnostic du paludisme](project_05_formation_hematologie_paludisme/README.md)

## Portée scientifique

Les données publiées sont synthétiques et servent à illustrer les méthodes. Elles ne constituent ni des dossiers patients, ni des résultats cliniques, ni des estimations de prévalence. Les limites et précautions d’interprétation sont indiquées dans chaque fiche.
