# Projet 06 — Santé publique infantile au Bénin

La fiche `index.html` affiche les 35 valeurs annuelles UNICEF Data/UN IGME (1990–2024), la provenance, les méthodes, les limites, une figure SVG et le script Python complet. Les données sont des estimations modélisées publiques, non des observations individuelles.

Pour régénérer la figure : `python scripts/reproduce.py` (Python 3).
